# Enduro.Zone

Сообщество эндуро: гараж, бортжурналы, маршруты, совместные покатушки, магазин, обучение и виртуальный механик.

Проект двух основателей — Смоленск и Сочи. Первая реализация готовится в отдельной ветке для совместного просмотра. Бренд пока рабочий; регистрация домена не выполнена.

Репозиторий: https://github.com/novokshonovpv/endurozone
