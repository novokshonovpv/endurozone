# Enduro.Zone

[Актуальный план, состояние и передача работы в Claude](docs/project-status.md) — единый документ версии 0.18. Исходные документы `docs/plan` сохраняются как архив концепции. [Проверка 0.16 и очередь пилота](docs/pilot-readiness.md), [требования к поставщику](docs/supplier-catalog.md).

Рабочая версия, 0.18.0. Сайт и отдельный сервер для сообщества эндуро. Проект двух основателей: Смоленск и Сочи.

Работает сценарий **аккаунт → мотоцикл → запись → комментарий другого участника**. Данные сохраняются в серверной базе. Аккаунты, мотоциклы и записи разных пользователей разделены правами доступа.

## Что реализовано

- Регистрация, вход, выход, сессия в HttpOnly-cookie; email виден только владельцу.
- Профиль: имя, ник, город, уровень и описание.
- Гараж нескольких мотоциклов: добавление, редактирование, переключение и удаление. Мотоцикл с записями нельзя случайно удалить.
- Бортжурнал с привязкой к мотоциклу: создание, редактирование и удаление, тип записи и видимость «Все» / «Только я».
- Обложка мотоцикла и до шести фотографий в записи: загрузка, просмотр и удаление с проверкой текущей видимости и удалением метаданных.
- Публичная лента с фильтрами города / типа, пагинация, комментарии и удаление своего комментария.
- Подписки на райдеров с приватными списками, лента подписок и личное избранное.
- Раздел «Рядом»: места, треки и покатушки в радиусе от геопозиции, города или точки на карте.
- Чат участников покатушки с модерацией и уведомления подписчикам о новых покатушках.
- Карта точек локаций, фильтр города, предложение места с координатами, сложностью и условиями доступа. Публичны только одобренные места.
- GPX 1.1: приватный оригинал, очищенная публичная геометрия, скрытие краёв, предпросмотр, модерация и скачивание.
- Покатушки на опубликованных треках: заявки, подтверждение / отказ, выход участника, лимит с учётом организатора, отмена. Точка сбора только для подтверждённых участников.
- Модерация локаций, причины решений, жалобы на публичные записи / места, скрытие контента, отдельная роль модератора.
- Адаптивный сайт, общие типы и схемы API, экспорт OpenAPI, серверные проверки, CI для встроенной базы и PostgreSQL.

Магазин открыт как демонстрационная витрина с вымышленными товарами и подбором. Подключение продавцов, торговля, очные тренировки, реальный ИИ-механик и мобильные приложения — следующие этапы.

## Запуск на компьютере

Нужны Node.js 24 и pnpm 11.25.0. Если pnpm отсутствует: `npm install -g pnpm@11.25.0`.

```sh
git clone https://github.com/novokshonovpv/endurozone.git
cd endurozone
git switch feat/timeweb-stand
pnpm install --frozen-lockfile
pnpm dev
```

Откройте **http://localhost:5173**. Сервер работает на http://127.0.0.1:3001. Первый запуск базы может занять несколько секунд. Для остановки — Ctrl+C.

Встроенная PGlite запускает PostgreSQL в процессе сервера и сохраняет файлы в `.data/postgres`. Установка Docker для первого запуска не нужна. Данные не хранятся в localStorage и не отправляются в старый Sites-прототип. Одновременно запускать два сервера с одной папкой базы нельзя.

База изначально пустая. Для просмотра создайте **тестовый** аккаунт, мотоцикл и запись; второй аккаунт используйте для проверки комментариев и закрытого доступа. Рабочие персональные данные до пилота не добавлять.

При необходимости создайте корневой `.env` по `.env.example`. Папка базы, `.env`, зависимости и сборки исключены из Git. Репозиторий сейчас публичный; доступы и личные данные в него не помещать. Проверку лицензии исходников и соглашение основателей ещё предстоит оформить.

## Обычный PostgreSQL

Используется та же SQL-модель, параметризованные запросы и миграции. Если установлен Docker:

```sh
docker compose -f infra/compose.yml up -d
```

В корневом `.env` задайте `DATABASE_URL=postgresql://enduro:enduro-dev-only@localhost:5432/enduro` и перезапустите сервер. Эта учётная запись предназначена только для локальной разработки. Перенос данных из встроенной базы не происходит автоматически. Точки сейчас используют широту / долготу без PostGIS. GPX-геометрия хранится в JSONB; пространственные запросы с индексом — отдельный следующий этап.

```sh
pnpm check

```

Для просмотра сборки на одном сервере установите `WEB_ORIGIN=http://localhost:3001` в `.env`, затем `pnpm start` и откройте http://localhost:3001. Для возврата к двум серверам восстановите `WEB_ORIGIN=http://localhost:5173`. OpenAPI: `/api/openapi.json` или `docs/api/openapi.json`.

## Граница готовности

Это локальная версия для разработки и проверки основателями. Фото хранятся в базе; юридические документы, резервное копирование и промышленное размещение ещё не готовы. Сервер в `NODE_ENV=production` требует PostgreSQL, HTTPS-origin и Secure-cookie, но это не заменяет подготовку к запуску.

Промышленный сервер и хранение данных размещаются отдельно после выбора инфраструктуры и согласования требований. Старый сайт-концепция остаётся самостоятельным прототипом. Домен не куплен и не подключён; Enduro.Zone остаётся рабочим именем, альтернативные доменные идеи сохранены в `docs/decisions/0002-brand.md`.

## Проверка карты вместе

Сначала создайте два тестовых аккаунта. Первый предлагает место в разделе «Карта локаций», второй проверяет его как модератор. Не вводите реальные частные адреса. Пустая карта после установки ожидаема: фиктивные маршруты не включены в базу.

Остановите локальный сервер и выдайте роль точному нику второго аккаунта:

```sh
pnpm moderator grant second_test_handle
pnpm dev
```

После входа у него появляется «Модерация». Причина проверки обязательна. Автор видит статус и результат в «Моих предложениях». Отзыв: остановите сервер и выполните `pnpm moderator revoke second_test_handle`. Не выдавайте роль случайному первому зарегистрированному аккаунту. Подробности — [регламент](docs/runbooks/moderation.md).

Подложка карты — OpenStreetMap через MapLibre. Для небольшого локального тестирования: стандартные HTTPS-тайлы, видимая атрибуция, штатный браузерный кэш, без офлайн-загрузки и массового предварительного скачивания. Перед публичным запуском нужно выбрать подходящий сервис карты и проверить его условия. [Документация MapLibre](https://maplibre.org/maplibre-gl-js/docs/examples/map-tiles/), [политика OSM](https://operations.osmfoundation.org/policies/tiles/).

Карта показывает только точки из загруженной страницы списка, дальше есть «Показать ещё». Персональная геопозиция «Моя позиция» только перемещает карту в браузере; не сохраняется в профиле и не отправляется нашему API. Запросы подложки поступают внешнему сервису OSM. Поиск по радиусу — в разделе «Рядом» (0.15). Редактирование предложения, повторная подача, апелляции и восстановление скрытого контента пока не реализованы.

## Совместная проверка GPX и покатушки

[Спринт 03](docs/sprint-03.md) описывает полный сценарий. Откройте «GPX-треки», загрузите **синтетический** GPX 1.1, проверьте публичную версию, заполните условия доступа и отправьте на проверку. Вторым аккаунтом модератора проверьте геометрию и решение.

Из опубликованного трека создайте покатушку. Другим участником подайте заявку и убедитесь, что точка сбора ещё скрыта. Организатор подтверждает заявку; место и сведения о сборе становятся доступны участнику. Организатор входит в лимит. Отказ участника освобождает место; отмена выезда убирает его из предстоящих и закрывает сведения о сборе для остальных.

Ограничения GPX: до 400 000 байт UTF-8, 5000 точек и 100 сегментов; GPX 1.1 с trk/trkseg/trkpt. Широта ±85°, разрыв между соседними точками до 2 км, публичная длина 50 м–500 км. Меридиан 180° пока не поддерживается. Скрытие краёв: радиус 100–2000 м вокруг начала и конца **каждого** сегмента, включая повторное прохождение этих участков; разрывы не соединяются. Это не гарантия анонимности всей поездки. [Регламент треков](docs/runbooks/tracks-rides.md), [спецификация GPX](https://www.topografix.com/gpx/1/1/).

Оригиналы GPX пока хранятся приватно в серверной базе, не в S3; к ним имеет доступ только автор, включая после публикации. Модератор проверяет очищенную версию. При скрытии трека связанные выезды исчезают из публичного списка, заявки и доступ участникам к сбору блокируются. Изменение геометрии и повторная подача пока не реализованы.

Нет чата, push/email-уведомлений о событиях, офлайн-навигации, поиска по радиусу, отдельного удаления / версии трека, предварительного одобрения событий и промышленного хранения файлов. Текущие даты вводятся во времени устройства; часовой пояс события задаёт только отображение. Для публичного пилота эти ограничения нужно проработать.

## Подготовка пилота · 0.6

Подтверждение email и восстановление пароля используют одноразовые ссылки (24 часа / 30 минут). Новый пароль завершает все прежние сеансы. Личные уведомления сообщают о заявке организатору, принятии / отказе участнику, отмене события и решении модератора по локации / треку. Данные о сборе не копируются в уведомления.

В разработке `MAIL_MODE=file`: письма сохраняются только в `.data/mail/*.txt`, без отправки в интернет. Каталог содержит приватные одноразовые ссылки и исключён из Git. Открывать файл локально, переходить по ссылке, после проверки удалять тестовые письма. Через сайт почтового ящика нет. Для SMTP заполнить переменные из `.env.example`; реальная доставка требует отдельной проверки с вашим провайдером.

`REQUIRE_VERIFIED_EMAIL=true` запрещает изменения основных данных до подтверждения адреса; операции с доступом и чтением уведомлений доступны. В разработке флаг выключен для прежних тестовых аккаунтов. В production флаг, SMTP, PostgreSQL, HTTPS и Secure-cookie обязательны. Подробности и совместная приёмка: [спринт 04](docs/sprint-04.md), [почта и доступ](docs/runbooks/pilot.md). Это ещё не публичный запуск.

## Данные аккаунта и модерация покатушек · 0.7

Жалобы теперь принимаются и на покатушки. Модератор может скрыть событие с причиной; участники теряют доступ к сбору. Организатор сохраняет собственные сведения. В разделе доступа есть выгрузка собственных данных и безвозвратное удаление аккаунта с паролем и точной фразой подтверждения. Удаление затрагивает основную базу, включая авторские GPX и связанные покатушки; архивные копии и локальные тестовые письма требуют действий оператора. Подробности и пределы выгрузки: [спринт 05](docs/sprint-05.md).

## Демонстрационный магазин · 0.8

В разделе «Магазин» доступны вымышленные запчасти, экипировка и мотоциклы, поиск, фильтры, сортировка и карточки товаров. Подбор использует выбранный мотоцикл из гаража; совпадение в демо-каталоге требует модели, года, двигателя и исполнения. Все цены и применимость демонстрационные. Продаж и подключения поставщиков пока нет. Совместная проверка: [sprint-06](docs/sprint-06.md). Общий тестовый сервер отложен.

## Личное обслуживание в гараже · 0.9

В гараже доступны личный план ТО по моточасам, запись выполненных работ с датами, расходами и заметками, архив и восстановление работ. Выполнение пересчитывает следующий срок и при необходимости увеличивает моточасы техники. Бортжурнал выбранного мотоцикла фильтруется на сервере до пагинации. Кнопка подбора запчастей передаёт выбранную технику в магазин. Интервалы задаёт владелец; автоматических уведомлений пока нет. Совместная проверка: [sprint-07](docs/sprint-07.md).

## Вводное обучение · 0.10

Три открытых урока: подготовка к выезду, история техники, подготовка к очному занятию. Личный прогресс чтения хранится на сервере, отметка обратима и привязана к версии материала. В уроках есть источники и переходы к гаражу, карте и покатушкам. Практические навыки, каталог школ и видеокурсы — будущие этапы. Совместная проверка: [sprint-08](docs/sprint-08.md).

## Виртуальный механик · 0.11

Личные консультации доступны зарегистрированным участникам: выбор своего мотоцикла, вопрос, ответ и история с удалением. Провайдер ИИ на выбор — YandexGPT, GigaChat или OpenAI (`MECHANIC_PROVIDER` и ключи провайдера на сервере, см. [подключение](docs/runbooks/mechanic-providers.md)); с российского сервера доступны YandexGPT и GigaChat. Текст согласия называет подключённого провайдера. Без них сайт прямо показывает, что ИИ не подключён; поддельных ответов нет. Ключ не передаётся браузеру.

В OpenAI отправляются вопрос и снимок марки, модели, года, двигателя и исполнения выбранной техники после явного согласия. Заметки, ТО, профиль, email, геопозиция и предыдущие вопросы автоматически не передаются. Не вводите персональные данные в текст вопроса. `store:false` отключает сохранение состояния Responses; это не обещание отсутствия иных журналов у провайдера. У каждого вопроса отдельный контекст.

Ограничения: 2000 символов вопроса, 1200 выходных токенов, таймаут 30 секунд, один одновременный запрос на аккаунт, 10 попыток в день UTC, 100 записей истории. Неудачная отправленная попытка тоже расходует лимит; удаление истории не сбрасывает его. Для пилота дополнительно задайте общий лимит расходов в кабинете провайдера. История и счётчики входят в выгрузку аккаунта и удаляются вместе с ним из основной базы.

Настоящие ответы в этой версии не проверены: ключ и модель не настроены. Тесты используют явный тестовый провайдер. До подключения нужно проверить доступность API для оператора, модель, бюджет и качество ответов на примерах, рассмотренных механиком. Источники/руководства, фото и продолжение диалогов — отдельный этап. [Совместная приёмка](docs/sprint-09.md). Общий тестовый сервер остаётся отложенным.

## Райдеры и публичные гаражи · 0.12

В разделе «Райдеры» находятся авторы открытых нескрытых записей. Поиск по имени/нику и городу, страницы участника, публичные мотоциклы и бортжурнал с фильтрами по технике и типу записи. Имя автора в ленте, записи и комментарии открывает его страницу; техника в карточке открывает публичный бортжурнал выбранного мотоцикла. Из своего профиля можно посмотреть публичную страницу.

В гараже райдера показаны только мотоциклы с открытыми нескрытыми записями и только уже публичные поля: марка, модель, год, исполнение. Моточасы, двигатель, личные заметки, план ТО, расходы, закрытые/скрытые записи, email и роль не выдаются. Даже владелец на этой странице видит публичную версию; полный гараж доступен отдельно. После закрытия или скрытия последней публичной записи техника исчезает из списка, автор без открытых записей — из поиска. Прямой публичный профиль, существовавший в предыдущих версиях, остаётся доступен без бортжурнала.

Город — текст, введённый участником; определения местоположения и поиска по радиусу пока нет. Подписок и личных сообщений пока нет. В версии 0.12 новых таблиц и внешних сервисов не добавлялось. [Приёмка спринта](docs/sprint-10.md).

## Фотографии · 0.13

В «Моём гараже» можно добавить или заменить одну обложку мотоцикла. После сохранения записи на её странице можно прикрепить до шести фото. Изображения видны в ленте, публичном гараже и журнале; открываются в увеличенном виде. Удаление требует подтверждения в интерфейсе.

Входные форматы JPEG, PNG и WebP, максимум 5 МБ и 24 мегапикселя, без анимации. Сервер проверяет содержимое, исправляет поворот, уменьшает фото до 1600 × 1600 и сохраняет JPEG без EXIF/GPS. Исходник и имя файла не сохраняются. Лимит аккаунта — 100 обработанных фото или 50 МБ. Обложка становится публичной при наличии открытой нескрытой записи о мотоцикле; фото записи наследуют её видимость. Прямая ссылка проверяет права при каждом новом запросе, ответы не кешируются.

Для этой версии обработанные изображения хранятся в PostgreSQL/PGlite, а не в публичной папке сайта. При удалении фото, записи, мотоцикла или аккаунта соответствующие изображения удаляются из рабочей базы. Выгрузка аккаунта включает собственные JPEG в base64; для большого архива действует ограничение текущего экспорта и потребуется оператор. Резервные копии удаляет оператор по отдельному регламенту. Объектное хранилище, CDN, очередь обработки, инструменты отдельной модерации изображений и фото для ИИ-механика — дальнейшие этапы.

[Совместная приёмка](docs/sprint-11.md).

## Подписки и избранное · 0.14

На странице райдера можно подписаться и отписаться. В «Сообществе» появилась вкладка «Мои подписки» — открытые нескрытые записи райдеров, на которых вы подписаны. Кнопка «В избранное» на странице записи сохраняет её в личный раздел «Избранное». Раздел «Подписки» показывает владельцу, на кого он подписан и кто подписан на него.

Списки подписчиков и подписок видит только владелец; остальным, включая гостей, показывается количество. О новом подписчике приходит уведомление на сайте без имени; пока оно не прочитано, новые не создаются. Избранное не расширяет доступ: закрытая или скрытая модератором запись пропадает из него при следующем открытии. Лимиты: 1000 подписок и 1000 записей в избранном. Подписки и избранное входят в выгрузку и удаляются вместе с аккаунтом. Миграция 010 добавляет таблицы `follows` и `favorites`.

[Решения и совместная приёмка](docs/sprint-12.md).

## Поиск рядом · 0.15

Раздел «Рядом» показывает ближайшие покатушки, проверенные места и опубликованные треки в радиусе 25–200 км (по умолчанию 100) с расстоянием по прямой. Центр поиска — геопозиция по кнопке, город из списка или точка на карте; без разрешения на геопозицию поиск работает по городу. Покатушка и трек находятся по ближайшей точке публичной очищенной линии трека — закрытая точка сбора не используется.

Центр округляется примерно до 1 км в браузере и на сервере, не сохраняется и не попадает в журнал запросов. Миграция 011 добавляет границы публичной линии треков и индексы по координатам. PostGIS не нужен. [Решения и совместная приёмка](docs/sprint-13.md).

## Чат покатушки и уведомления подписчикам · 0.16

На странице покатушки организатор и подтверждённые участники переписываются в «Чате участников». Чат открыт и после старта; при отмене — только чтение, при скрытии модератором участникам недоступен. Автор удаляет своё сообщение, организатор скрывает любое, участник может пожаловаться — модератор видит только это сообщение, не весь чат и не точку сбора. Подписчики организатора получают уведомление о новой покатушке без имени и названия. В «Рядом» треки и покатушки отмечены на карте. Миграция 012 добавляет `ride_messages`. Мгновенной доставки и уведомлений о новых сообщениях пока нет. [Решения и совместная приёмка](docs/sprint-14.md).

## Обратная связь пилота · 0.17

У вошедшего участника на каждой странице есть кнопка «Отзыв»: тип (сломалось / непонятно / идея) и описание; раздел сайта (без идентификаторов записей), экран, браузер и версия прикладываются автоматически. Свои отзывы и ответы — в «Моих отзывах». Модераторы разбирают очередь в «Отзывах пилота» и отвечают; автор получает уведомление о закрытии или новом ответе. Отправка доступна и без подтверждённого email. Миграция 013 добавляет `feedback`. [Решения и приёмка](docs/sprint-15.md). Закрытый тестовый стенд — `deploy/README.md`.

## Первые шаги и активация пилота · 0.18

Новичок видит в «Сообществе» и «Гараже» карточку «Первые шаги»: мотоцикл → запись → подписка → шаг к другим (комментарий, избранное, заявка). Галочки ставятся по сохранённым данным, без отслеживания кликов; карточку можно скрыть. Модераторы видят в «Отзывах пилота» сводку активации и возврата через неделю — только числа, без модераторов и синтетических аккаунтов `@example.test`. Миграция 014. [Решения и приёмка](docs/sprint-16.md).
