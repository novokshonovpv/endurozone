# Будущий мобильный клиент

iOS и Android используют тот же API и аккаунт. Контракты — в packages/contracts, OpenAPI — в docs/api.

Сейчас для Android есть оболочка над сайтом — [apps/android](../android/README.md) (Trusted Web Activity, 0.20). Нативного клиента пока нет.

Первый отдельный эксперимент N01: React Native или привычный другу стек, карта на двух устройствах, GPS и условия офлайн-данных. Решение принимается после обсуждения с техническим основателем.
