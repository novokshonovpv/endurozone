Пароль можно вернуть: `STAND_GENERATE_PASSWORD=1` при `setup` (если файла конфигурации nginx ещё нет) или вручную в `/etc/nginx/sites-available/endurozone.conf`; снять снова — `bash stand.sh open`.

Пока стенд открыт, зарегистрироваться может любой, кто знает адрес, а ИИ-механик расходует ключ GigaChat владельца (лимит 10 вопросов в день на аккаунт, аккаунтов — сколько угодно). Отключить механика: удалить строки `MECHANIC_`/`GIGACHAT_` из `/etc/endurozone.env` и `systemctl restart endurozone`.

Это не промышленный запуск: встроенная база PGlite, письма не отправляются (`MAIL_MODE=file`), подтверждение email выключено, регулярное резервное копирование не настроено; ручная копия создана и проверена 10.10.2026. Используйте только тестовые данные.

## Устройство

10.10.2026 пользователь подтвердил, что сайт открывается с его стороны. Из окружения разработки DNS успешно возвращает IP, но HTTPS обрывается с `UNEXPECTED_EOF_WHILE_READING`, SSH — `Connection closed`. Серверные проверки и восстановление поэтому не выполнены.

Подготовлен `deploy/backup.py`: копирование PGlite при остановленном сервисе и проверка архива. Семь локальных тестов успешны; [порядок копирования и приёмки восстановления](../docs/runbooks/stand-backups.md). Позднее в этот день ручная копия создана и проверена через консоль — см. отчёт выше.

```text
/opt/node-v24                      Node.js 24 (официальная сборка, проверка SHA-256)
/opt/endurozone/app                клон репозитория, ветка стенда
/opt/endurozone/app/.data          база стенда и локальные письма (не трогать при обновлении)
/etc/endurozone.env                переменные окружения (HOST=127.0.0.1, порт 3201, HTTPS-origin)
/etc/systemd/system/endurozone.service   служба под пользователем enduro
/etc/nginx/sites-available/endurozone.conf  свой server-блок; другие сайты не меняются
/etc/nginx/endurozone.htpasswd     хеш общего пароля стенда (только если пароль включён; с 13.10.2026 файла нет)
```

Сервер слушает только 127.0.0.1; снаружи доступ через nginx с паролем и HTTPS. `TRUST_PROXY=true` — лимиты запросов считаются по реальному IP посетителя из заголовка nginx.

## Обновление

С компьютера с доступом `ssh timeweb` (root):

```sh
ssh timeweb "bash -s -- update feat/timeweb-stand" < deploy/stand.sh
```

Вместо `feat/timeweb-stand` можно указать другую опубликованную ветку. Скрипт берёт её из GitHub, ставит зависимости, собирает сайт, перезапускает службу и проверяет `/api/health`. База сохраняется.

## Полезное

```sh
ssh timeweb "systemctl status endurozone --no-pager"
ssh timeweb "journalctl -u endurozone -n 100 --no-pager"
ssh timeweb "systemctl stop endurozone && cd /opt/endurozone/app && sudo -u enduro env PATH=/opt/node-v24/bin:/opt/endurozone/tools/bin:/usr/bin:/bin pnpm moderator grant <ник> && systemctl start endurozone"
```

Письма подтверждения и восстановления пароля стенд не отправляет — они лежат в `/opt/endurozone/app/.data/mail`.

## Первичная настройка

Из веб-консоли Timeweb (root) одной командой — пароль стенда сгенерируется и будет показан в конце:

```sh
curl -fsSL https://raw.githubusercontent.com/novokshonovpv/endurozone/feat/timeweb-stand/deploy/console-setup.sh | bash
```

Или по SSH: `STAND_HOST=enduro.200-165-236-78.sslip.io STAND_PASSWORD_STDIN=1 bash stand.sh setup`, на stdin — логин и пароль стенда (две строки). Повторный запуск безопасен: база и пароль сохраняются.
