# Спринт 20 — четыре блока и стеклянный дизайн · 0.24

## Результат

Навигация собрана в **четыре блока** — одинаково в веб-версии (боковая панель) и на телефоне (нижнее меню):

| Блок           | Вкладки                                                                 |
| -------------- | ----------------------------------------------------------------------- |
| **Сообщество** | Лента (все и подписки) · Новости · Мероприятия · Райдеры                |
| **Маршруты**   | Карта · Места · Прокаты и гиды · Треки · Покатушки · Обучение           |
| **Игра**       | без изменений                                                           |
| **Гараж**      | Мои мотоциклы · Обслуживание · Запчасти · ИИ-механик · Модели · Магазин |

- Вкладки блока — сегментированный переключатель над страницей (на телефоне листается вбок). Старые адреса (`#map`, `#tracks`, `#rides`, `#parts`…) работают и попадают в свой блок.
- Личные разделы (подписки, избранное, профиль, доступ к аккаунту, модерация) — под заголовком «Моё» в боковой панели, на телефоне — в «Меню».
- **Новости** (`#news`) — записи нового типа «Новость». Публикуют только модераторы (API отвечает 403 `MODERATOR_REQUIRED`), остальные видят ленту новостей.
- **Мероприятия** (`#events`) — ближайшие открытые покатушки, сгруппированные по месяцам, как анонсы.
- **Обслуживание** (`#service`) — блоги об обслуживании и доработках (записи бортжурналов этих типов) внутри Гаража.
- **Прокаты и гиды** (`#services`) — новые типы точек на карте: прокат, гид, школа. У них нет сложности, зато есть контакты и «Условия и цены». Фильтр: все / прокаты / гиды / школы. Проходят ту же модерацию, что и места.
- **Карта** (`#nearby`) — единая: покатушки, треки, места и прокаты с гидами, слои включаются фильтрами-чипами. У каждого вида свой цвет и буква маркера: М — место, Т — трек, П — покатушка, ₽ — прокат, Г — гид, Ш — школа.
- **Магазин** вернулся — вкладкой в Гараже.

## Решения

Пользователь 14.10.2026: четыре крупных блока для мобильной и веб-версии; «Райдеры» и «Обучение» — на усмотрение. Выбрано: **Райдеры → Сообщество** (это люди), **Обучение → Маршруты** (школы и инструкторы рядом с прокатами и гидами, уроки — подготовка к выезду).

Дизайн «ближе к Apple, прозрачные окна, оливковый и охра»:

- полупрозрачные карточки с размытием фона (`backdrop-filter`), крупные скругления 18–28 px, мягкие тени;
- системный шрифт (SF на Apple, Onest на остальных), заголовки без капса; шрифт Russo One больше не загружается;
- палитра: тёмная олива `#2F3520` / `#4B5320`, охра `#C9892B` / `#E3B04B`, тёплый светлый фон с размытыми пятнами оливы и охры;
- кнопки-«пилюли» (основная — олива, акцентная — охра), теги-пилюли, без срезанных углов;
- боковая панель — тёмное оливковое матовое стекло, верхняя панель и нижнее меню телефона — светлое матовое стекло.

Слой стилей — `apps/web/src/glass.css` (подключается последним, поверх `theme.css`).

- Миграция `018-map-kinds-news.sql`: `locations.kind` (`spot` | `rental` | `guide` | `school`, по умолчанию `spot`), `locations.contacts`, сложность стала необязательной (обязательна только для мест), тип записи `news`.
