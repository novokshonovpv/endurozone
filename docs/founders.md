# Вопросы для двух основателей

Для обсуждения до существенных вложений. Документ ещё не заполнен и не является подписанным договором.

| Решение | Договорённость |
|---|---|
| Вклад временем и деньгами, доли | Обсудить |
| Владелец кода, бренда, домена и материалов | Обсудить |
| Технические решения / продукт / принятие расходов | Обсудить |
| Лимит самостоятельных расходов | Обсудить |
| Права и восстановление доступов | Обсудить |
| Отсутствие одного участника, выход и спор | Обсудить |
| Возмещение затрат и будущая выручка | Обсудить |
| Форма бизнеса и оформление прав | Обсудить с профильной помощью |

Текущее распределение: друг — сервер и мобильные приложения; вы — продукт, сайт, сообщество, партнёры и остальные задачи. Доли не считаем автоматически равными. Пароли и резервные коды не записываем в этот репозиторий.
