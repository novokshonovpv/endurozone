# Enduro.Zone — сводка для подключения к проекту

Для второго основателя (сервер и мобильные приложения). Состояние на 17.10.2026, версия **0.31.0**. Подробная история — в [project-status.md](project-status.md) и `docs/sprint-*.md`.

## 1. Что это и где лежит

- **Продукт:** сообщество эндуро-райдеров России и Беларуси. Четыре блока: Сообщество (лента, новости, мероприятия, райдеры), Маршруты (единая карта, места, прокаты и гиды, треки, покатушки, обучение), Игра, Гараж (мотоциклы, ТО, запчасти, ИИ-механик, модели, магазин).
- **Репозиторий:** https://github.com/novokshonovpv/endurozone, рабочая ветка — `main` (на GitHub только `main` и `feat/mobile-tabbar`, через которую сейчас идут изменения и сразу перематываются в `main`).
- **Стенд:** https://enduro.200-165-236-78.sslip.io — сервер Timeweb, открыт без общего пароля, индексация закрыта.
- **Android:** своё приложение-оболочка на WebView, открывает стенд (`apps/android`, сборка 5). Изменения сайта пересборки не требуют.

## 2. Стек

| Часть                | Технологии                                                                                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apps/api`           | Node.js 24, Fastify 5, TypeScript через tsx. База — PGlite (встроенный PostgreSQL в файле `.data/`) локально и на стенде; при `DATABASE_URL` — обычный PostgreSQL (CI проверяет на PostgreSQL 17) |

| Карта                | MapLibre GL + тайлы OpenStreetMap (загружается только на страницах с картой)                                                                                                                      |

## 3. Запуск локально

Нужны Node.js 24 и pnpm 11 (`npm exec pnpm@11.25.0 -- …`, если pnpm не установлен).

```bash
pnpm install
pnpm dev          # сайт http://localhost:5173, API http://127.0.0.1:3001
pnpm check        # проверка типов во всех пакетах
pnpm test         # тесты API (167 на 17.10.2026)
pnpm build        # сборка сайта в apps/web/dist
pnpm api:export   # docs/api/openapi.json — обновлять при изменении схем
```

Локальная база создаётся сама в `.data/` при первом запуске (миграции и стартовое наполнение).

## 4. Как устроен код

- `apps/api/src/app.ts` — сборка приложения: защита (сессия, CSRF, проверка источника, лимиты, заголовки), регистрация модулей. Каждый раздел — свой модуль: `locations.ts`, `adventure.ts` (треки и покатушки), `nearby.ts`, `announcements.ts` и `announcement-import.ts`, `parts.ts`, `models.ts`, `mechanic.ts`, `share.ts` (превью ссылок, sitemap), `stats.ts`, `reminders.ts`, `seed.ts` и т. д.
- `apps/api/migrations/0NN-*.sql` — последовательные миграции, список в `database.ts`; тест `locations.test.ts` сверяет их количество.
- `apps/api/data/` — справочники и стартовое наполнение: модели 67МОТО, состав узлов KAYO, места из OpenStreetMap, анонсы гонок.
- `apps/web/src/App.tsx` — оболочка и маршруты (адреса через `#`), `sections.tsx` — четыре блока и их вкладки, разделы кроме ленты грузятся по требованию.

## 5. Правила, которые держим

- **Секреты не в Git:** `.env`, `.data`, ключи, дампы, ключ подписи Android (лежит вне репозитория у владельца, `%USERPROFILE%\.enduro-android\keys`).
- **Каждая функция — с тестом.** Тест `access-matrix.test.ts` проходит по всем операциям из OpenAPI и не даст случайно открыть модераторское или личное; ответы API идут через схемы (лишние поля отрезаются).
- **Личное не публикуется:** точка сбора — только организатору и принятым; отметки «Был здесь» — владельцу; страницы превью описывают только видимое гостю.
- **Чужие данные — только с правом:** места из OpenStreetMap с атрибуцией; GPX с чужих сервисов не копируем; анонсы гонок — факты со ссылкой на источник, публикует модератор.
- Не переименовывать бренд и домен, не включать платные сервисы и не сливать PR без решения владельца.

## 6. Стенд

| Что                  | Где                                                                                                                    |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| Приложение           | `/opt/endurozone/app` (пользователь `enduro`), Node — `/opt/node-v24`                                                  |
| База и письма стенда | `/opt/endurozone/app/.data` — не трогать при обновлении                                                                |
| Настройки            | `/etc/endurozone.env` (ключ GigaChat, флаги); `COOKIE_SECURE=true`, `TRUST_PROXY=true`, `REQUIRE_VERIFIED_EMAIL=false` |
| Сервис               | `systemctl status                                                                                                      | restart endurozone`, журнал — `journalctl -u endurozone` |
| nginx                | `/etc/nginx/sites-available/endurozone.conf`, HTTPS Let's Encrypt                                                      |
| Копии                | ежедневно в 23:30 МСК ([runbooks/daily-backups.md](runbooks/daily-backups.md)); внешней копии пока нет                 |

Обновление до свежего `main` (сейчас через серийную консоль Timeweb, можно по SSH):

```bash
bash /root/enduro-stand.sh update main
```

После обновления `GET /api/health` отвечает версией. Назначить модератора — `pnpm moderator grant <ник>` (см. [deploy/README.md](../deploy/README.md)). Письма стенд наружу не отправляет — они складываются в `.data/mail`.

Фоновые задачи сервера: стартовое наполнение при запуске (один раз по ключу), черновики анонсов из `t.me/s/raceenduro` раз в 6 часов (`ANNOUNCEMENT_CHANNELS`, `ANNOUNCEMENT_IMPORT=false`), напоминания о покатушках раз в 30 минут.

## 7. Android

Сборка — [apps/android/README.md](../apps/android/README.md) (JDK 17, Gradle 8.9, короткие пути из-за кириллицы в профиле Windows). При новой сборке увеличивать `versionCode`; подписывать тем же ключом (отпечаток SHA-256 `563B90AC…59DF`), иначе обновление не встанет поверх. Приложение использует свой WebView: выбор файлов, геопозиция, загрузки, игра в горизонтальном режиме, офлайн-страница.

## 8. Что ждёт в первую очередь (сервер и приложения)

1. **Почта (SMTP)** → затем включить `REQUIRE_VERIFIED_EMAIL=true`: сейчас регистрироваться может кто угодно с любым адресом.
2. **Внешняя резервная копия** базы (например, Yandex Object Storage).
3. **PostgreSQL** вместо PGlite на стенде/продакшене (код готов, CI проверяет).
4. **Push-уведомления** в Android (Firebase) — уведомления сейчас только внутри сайта.
5. **iOS**-оболочка по образцу Android.
6. **Домен** enduro.zone (решение и покупка — за основателями), затем перенос стенда.
7. Блокировка аккаунта после серии неудачных входов (сейчас лимит по адресу).

Отчёт о проверке безопасности и открытые рекомендации — [security-review-2026-10.md](security-review-2026-10.md). Документация API — [api/README.md](api/README.md) и `api/openapi.json`.
