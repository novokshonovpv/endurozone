# Спринт 23 — превью ссылок и черновики анонсов из канала · 0.27

## Результат

### Превью ссылок в мессенджерах и поиске

- Кнопка **«Поделиться»** на месте/прокате, треке, покатушке, гонке, записи бортжурнала и модели. На телефоне открывает системное меню «Поделиться», на компьютере копирует ссылку.
- Ссылка вида `/s/place/<id>` (а также `track`, `ride`, `race`, `post`, `model`) отдаёт короткую страницу с заголовком и описанием именно этого объекта в тегах Open Graph — Telegram, VK, WhatsApp показывают карточку — и сразу открывает обычную страницу сайта. Сайт работает на адресах с «#», которые мессенджеры не передают серверу, поэтому нужен отдельный адрес.
- Описывается только то, что видно гостю: скрытое, неопубликованное, личное и отменённое получает общую карточку сайта (404). Точка сбора покатушки не читается. Текст райдеров экранируется.
- Картинка превью — `apps/web/public/og.png` (1200×630, олива и охра; `node scripts/og-image.mjs`), у моделей — фото модели. Главная страница тоже получила теги превью с адресом текущего развёртывания.
- Для поисковиков: `/sitemap.xml` (места, треки, открытые покатушки, гонки, 863 модели) и `/robots.txt`.

### Черновики анонсов гонок

- Сервер раз в 6 часов (и по кнопке «Проверить канал») читает открытую веб-версию канала `t.me/s/raceenduro` и превращает новые анонсы в **черновики**: название, даты (в том числе «31 октября-01 ноября»), регион и место, классы, дисциплина по словам из текста, отмена и перенос.
- Черновики видят только модераторы — блок вверху «Мероприятий». «Проверить и опубликовать» открывает форму, заполненную разбором; «Не нужно» убирает черновик. Без модератора на сайт ничего не попадает.
- Пропускаются: посты без даты и названия (дайджесты, обсуждения), прошедшие гонки, уже опубликованные анонсы (по ссылке или по названию и дате), уже разобранные посты. Текст поста хранится только для модератора и публично не показывается.
- Настройки окружения: `ANNOUNCEMENT_CHANNELS` (по умолчанию `raceenduro`, можно несколько через запятую), `ANNOUNCEMENT_IMPORT=false` — выключить.

## API

- `GET /s/{type}/{id}`, `GET /sitemap.xml`, `GET /robots.txt` — служебные страницы, не входят в OpenAPI.
- `GET /api/moderation/announcement-drafts`, `POST …/refresh`, `POST …/{id}/publish`, `POST …/{id}/dismiss` — только модераторы.
- Миграция `020-announcement-drafts.sql`.
- Тесты: `share.test.ts`, `announcement-drafts.test.ts`.
