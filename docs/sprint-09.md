# Спринт 09 · Виртуальный механик · 0.11

Результат: раздел с выбором мотоцикла, вопросом, согласием на передачу в OpenAI и личной историей. Без настройки провайдера отправка недоступна. Общий HTTPS-сервер отложен по решению основателя.

## Совместная приёмка

1. Откройте `#mechanic` гостем: история недоступна, видны объяснение и вход.
2. Войдите: список содержит только собственные мотоциклы. Выберите технику и проверьте показанные основные данные.
3. Без ключа и модели должен быть статус «Ответы ИИ пока не подключены» и отключённая отправка.
4. Друг на сервере настраивает обе переменные из `.env.example`, сверяет доступность API для оператора и устанавливает бюджет в кабинете провайдера. Никогда не коммитьте `.env` и не используйте `VITE_*` для ключа.
5. После подключения на тестовых неперсональных вопросах проверьте ответ, перезагрузку и сохранение истории, удаление своей записи и отсутствие доступа из другого аккаунта. Каждый вопрос независим: предыдущая переписка не отправляется.
6. При сбое вопрос остаётся со статусом ошибки; сырые ошибки провайдера и ключ не показываются. Повторная попытка считается новым вопросом.
7. Проверьте выгрузку/удаление аккаунта на отдельных тестовых пользователях.
8. До пилота механик оценивает ответы: неизвестные спецификации, неполная модель, опасная неисправность, запрос выдуманного артикула, попытка изменить системные инструкции. Автоматические тесты не подтверждают качество настоящей модели.

## Реализация и пределы

- `GET /api/mechanic`: доступность и дневной лимит, без секретов.
- `GET /api/me/mechanic?offset=0`: только собственная история, 10 записей страницы.
- `POST /api/me/mechanic`: `{question,bikeId:null|uuid,consent:true}`; сессия, доверенный Origin, CSRF, подтверждение email в production.
- `DELETE /api/me/mechanic/:id`: только своя запись; дневной счётчик остаётся.
- Дневная квота и одновременные запросы защищены транзакцией с блокировкой пользователя; внешняя сеть вызывается после освобождения транзакции. Зависшая запись старше двух минут переводится в ошибку при следующем вопросе.
- Статусы pending/answered/failed; снимок техники сохраняется даже при удалении/изменении мотоцикла. Данные пользователя каскадно удаляются из основной базы.
- Согласие относится к конкретному вопросу; заметки, ТО, профиль и геопозиция автоматически не отправляются.
- Responses API: `store:false`, без Conversations/previous_response_id и инструментов, 30 секунд и 1200 выходных токенов. Это не Zero Data Retention; условия хранения провайдера проверяются отдельно.
- Текст ответа отображается как текст, без HTML. Нет загрузки фото, многотурового диалога, поиска по руководствам, ручной проверки каждого ответа, диагностики по телеметрии.
- Квота на аккаунт не заменяет общий бюджет и защиту от массовой регистрации для публичного запуска.
