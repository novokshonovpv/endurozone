# 0001 — первый сквозной сценарий

Статус: реализовано для локальной проверки, ожидает согласования с техническим основателем.

Сохраняем модульный сервер и общий API из первоначального плана. Первый срез ограничен аккаунтом, гаражом, текстовыми записями и комментариями. Внешние магазины, оплата, геопозиция и ИИ не подключаются без данных и процессов следующих этапов.

Сайт: React / TypeScript / Vite. Сервер: TypeScript / Fastify. Общие схемы в отдельном пакете. SQL совместим с PostgreSQL; встроенная PGlite позволяет запустить первый вариант без Docker. При `DATABASE_URL` сервер использует обычный драйвер pg. PostGIS потребуется при реализации карты, сейчас пространственные данные не хранятся.

Для локального запуска используем PGlite только на сервере, не в браузере. Это одна база и один процесс; встроенный режим не предназначен для промышленного кластера. Переключение на PostgreSQL не переносит локальные записи автоматически.

Сессии: непрозрачный случайный токен в HttpOnly-cookie, в базе хеш; срок 7 дней, отзыв при выходе. CSRF и проверка Origin для изменений. Внешний вход и мобильный способ авторизации согласуем позднее.

Выбор React Native не завершён: ждём привычный стек друга. Для приложения уже выделена папка и доступен контракт, само приложение не создано.

Основания: [параметризованные запросы PGlite](https://pglite.dev/docs/), [схемы Fastify](https://fastify.dev/docs/latest/Reference/Validation-and-Serialization/), [scrypt Node.js](https://nodejs.org/api/crypto.html#cryptoscryptpassword-salt-keylen-options-callback). Это ссылки на технические свойства, а не подтверждение готовности проекта к запуску.
