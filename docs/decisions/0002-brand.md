# 0002 — рабочий бренд и альтернативы

Рабочее имя остаётся **Enduro.Zone**, доменная идея — `enduro.zone`. Слоган: «Твоя территория эндуро». Регистрация домена и проверка товарных знаков ещё не выполнены.

По просьбе основателя сохраняем альтернативные доменные идеи без переименования:

- enduro.my
- enduro.army
- enduro.energy
- enduro.guide
- enduro.band

Свежая доступность, продление и права для этих вариантов не проверены. Новое имя не выбираем автоматически; решение принимается основателями отдельно.
