# Спринт 04: доступ и личные уведомления

Версия 0.6.0 добавляет подтверждение email, восстановление пароля и уведомления внутри сайта. SMTP-адаптер готов к подключению; сейчас письма сохраняются локально, реальные сообщения не отправляются.

## Приёмка основателями

1. Использовать два тестовых аккаунта и синтетическую покатушку, без реального выезда. Открыть «Доступ к аккаунту», запросить письмо и найти его в `.data/mail` по получателю.
2. Открыть ссылку подтверждения и нажать кнопку. Повторное использование должно завершиться сообщением об истекшей / недействительной ссылке. Проверить статус аккаунта.
3. Включить `REQUIRE_VERIFIED_EMAIL=true` локально, перезапустить API. Неподтверждённый аккаунт не меняет основные данные; после подтверждения изменения доступны. Не включать SMTP для этих синтетических адресов.
4. Запросить восстановление. Проверить успешный новый пароль, отказ старому и завершение всех прежних сеансов. Повторный запрос в минуту не создаёт ещё одно письмо.
5. Участник подаёт заявку на тестовую покатушку. Организатор получает уведомление. После принятия уведомление получает участник; после отмены — активные участники / заявители.
6. Проверить отметку «Прочитано», обновление счётчика и недоступность чужого уведомления. Точка сбора остаётся только в защищённом разделе покатушки.
7. Удалить локальные тестовые письма. Вернуть настройки разработки при необходимости. Зафиксировать замечания в GitHub со сценарием и ожидаемым результатом.

Бэкенд: подключение SMTP, эксплуатация очереди, проверка PostgreSQL и дальнейший мобильный клиент. Продукт: сценарии входа, тексты, правила уведомлений, модерация событий и приёмка. [Почта и ограничения](runbooks/pilot.md).

Следующий этап: модерация событий, удаление / экспорт аккаунта, развёртывание закрытого стенда с HTTPS и настоящей почтой, проверка резервных копий и восстановления. Текущая версия ещё не является публичным пилотом.
