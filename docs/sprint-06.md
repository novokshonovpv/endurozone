# Магазин · версия 0.8

Общий тестовый сервер отложен по решению основателя. Этот этап добавляет демонстрационную витрину без торговли.

## Что проверить вместе

1. Открыть «Магазин» гостем. Видны запчасти, экипировка, мотоциклы и явная отметка демонстрации. Все девять товаров, бренд EZ, цены и применимость вымышлены.
2. Выбрать «Демо: EZ Trail 250 · 2024 · Standard». Включить «Только совпадения в демо-каталоге»: остаются фильтр, колодки и защита. Комплект привода другой модели и рычаг без применимости не попадают в подбор.
3. Проверить поиск по артикулу, разделы, обе сортировки по цене, пустой результат и сброс фильтров. Открыть товар, проверить характеристики и таблицу применимости. Прямая ссылка `#shop/ez-filter` открывается гостем; неизвестный артикул показывает отсутствие товара.
4. Войти и выбрать мотоцикл из своего гаража. Его данные загружаются через существующий закрытый `/api/me/bikes`. Каталог не получает список чужих мотоциклов. Совпадение требует полного производителя, модели, года в диапазоне, двигателя и исполнения. Неизвестное значение не означает несовместимость: показывается «Совместимость не подтверждена».
5. Проверить мобильный вид, клавиатуру и выход из аккаунта. Выбранный приватный мотоцикл при смене пользователя очищается. Демо-модель не добавляется в гараж.

## Границы этапа

`GET /api/catalog` — открытая статическая демонстрационная выгрузка через общий API. Это основа интерфейса, а не импорт партнёра или подтверждённая применимость. Нет заказов, оплаты, корзины, остатков, продавцов, доставки, фотографий и управления каталогом. Экипировка не подбирается по мотоциклу; размеры пока показаны справочно в вымышленных карточках.

Следующий шаг магазина: получить от партнёра небольшой реальный файл с товарами, артикулами, изображениями с правом публикации, ценами, остатками и применимостью. Согласовать идентификаторы моделей/исполнений и правила обновления. Только после этого добавлять проверенную совместимость. Свободные поля гаража пока не сверены с каталогом производителя. Общий HTTPS-стенд остаётся отдельным отложенным этапом.
