# Спринт 10 · Райдеры и публичные гаражи · 0.12

Результат: раздел «Райдеры», страницы участника, публичная техника и открытый бортжурнал. Новые внешние подключения и миграции не требуются. Общий тестовый сервер остаётся отложенным.

## Проверка вдвоём

1. На отдельных тестовых аккаунтах добавьте мотоциклы и открытые/закрытые записи. Автор только закрытых записей не должен попадать в поиск.
2. Гостем откройте «Райдеры»: найдите автора по имени/нику и городу, перейдите на страницу. Город — поле профиля, а не геопозиция.
3. Публичный гараж показывает только мотоциклы с открытыми нескрытыми записями. Сверьте марку, модель, год, исполнение и число открытых записей.
4. Проверьте, что моточасы, двигатель, заметки, ТО, расходы, email, роль и закрытые записи не появились. Владелец в публичном представлении тоже не видит эти данные; для них есть «Мой гараж».
5. Выберите мотоцикл и тип записи, откройте запись, автора и автора комментария. Перезагрузите ссылку с `?bike=...`: фильтр техники должен сохраниться. Другую технику этого автора можно выбрать отдельно.
6. Закройте последнюю открытую запись техники: после обновления она должна исчезнуть из публичного гаража. Скройте открытую запись модератором — результат аналогичен. Когда открытых записей нет, автор исчезает из списка райдеров, но его существующий публичный профиль остаётся доступен напрямую.
7. Проверьте пустой город/имя, неизвестный профиль, технику другого автора и страницы на телефоне. Пагинацию проверьте на тестовых аккаунтах с более чем 12 записями/мотоциклами.

## Границы видимости

Критерий публикации: `visibility='public' AND NOT hidden`. Он применяется в запросах каталога, счётчиков, техники и бортжурнала до лимита страницы. Указание закрытого, чужого или неизвестного мотоцикла даёт одинаковый 404. Сессия владельца не расширяет публичные ответы. Исходные личные заметки не копируются в новые таблицы — новых таблиц нет.

Профили показывают уже публичные имя, ник, город, уровень и описание; город/уровень заявлены самим райдером. Нет определения геопозиции, поиска по радиусу, личных сообщений, подписок, фото и отдельной настройки публикации техники вне бортжурнала. Сохранённые у посетителя старые страницы не отзываются; после закрытия записи новые запросы её уже не возвращают.

## API

| Адрес | Параметры | Ответ |
| --- | --- | --- |
| `/api/riders` | q, city, limit 1–30, offset 0–10000 | Page<Rider>, только авторы открытых записей |
| `/api/profiles/:handle/bikes` | limit, offset | Page<PublicBike>, без приватных полей |
| `/api/profiles/:handle/posts` | bikeId, kind, limit, offset | Page<Post>, только открытые нескрытые записи |

Поиск нечувствителен к регистру; символы SQL-шаблонов экранированы, запросы параметризованы. Каталог сортируется по имени и id, техника — по дате создания и id, записи — по дате публикации и id. При изменении данных между страницами возможны обычные для offset-пагинации сдвиги.
