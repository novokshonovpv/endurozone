# Контракт первого среза

Версия 0.7.0. Схемы запросов и ответов находятся в `packages/contracts/src/index.ts`, сгенерированный документ — `openapi.json`. Сервер проверяет типы, длину полей, допустимые значения и лишние поля, а ответы ограничивает описанными публичными свойствами.

## Сессия

- `POST /api/auth/register`: email, password (12–128 символов), handle (3–24 строчные латинские буквы / цифры / `_`), displayName, city, level.
- `POST /api/auth/login`: email и password. Ответ `{ user, csrfToken }` и cookie `ez_session`.
- `GET /api/me`: текущая сессия. 401 означает гостя. Email присутствует только в собственной сессии.
- `POST /api/auth/logout`: отзывает серверную сессию и cookie.

Изменяющие запросы требуют `X-Enduro-Client: web`. Для защищённых изменений также требуется `X-CSRF-Token` со значением из сессии. Cookie — HttpOnly, SameSite=Lax, 7 дней; в промышленном окружении обязательно Secure. CSRF-токен хранится клиентом в памяти, cookie не копируется в localStorage. Не отправлять сессию или пароль в URL.

Origin проверяется по `WEB_ORIGIN`; для локального HTTP разрешён эквивалент localhost / 127.0.0.1 на том же порту. Произвольный cross-origin доступ не разрешён. Мобильный клиент будет использовать этот API через отдельное согласованное решение для сессий; готовый мобильный вход сейчас не заявлен.

| ----------------------------- | ---------------------------------------------- |

| GET /api/profiles/{handle}    | Публичный профиль, без email                   |
| GET /api/me/bikes             | Только собственный гараж                       |
| POST /api/me/bikes            | Создать мотоцикл                               |
| PATCH /api/me/bikes/{id}      | Изменить собственный мотоцикл                  |
| DELETE /api/me/bikes/{id}     | Удалить пустой мотоцикл; 409 если есть записи  |
| GET /api/feed                 | Публичные записи, city / kind / limit / offset |
| GET /api/me/posts             | Собственные записи, включая закрытые           |
| GET /api/posts/{id}           | Публичная запись или собственная закрытая      |
| POST /api/posts               | Создать запись только к собственному мотоциклу |
| PATCH /api/posts/{id}         | Изменить собственную запись                    |
| DELETE /api/posts/{id}        | Удалить собственную запись и её комментарии    |
| GET /api/posts/{id}/comments  | Комментарии только доступной записи            |
| POST /api/posts/{id}/comments | Комментировать доступную запись после входа    |
| DELETE /api/comments/{id}     | Удалить собственный комментарий                |

Пагинация: `{ items, nextOffset }`, `nextOffset: null` означает конец. `limit` 1–30, по умолчанию 12; `offset` 0–10000. Типы записей: `ride`, `maintenance`, `build`; видимость `public`, `private`. Город — явный профильный текст. Геопозиция профиля не собирается; координаты предлагаемого места публикуются после проверки.

Для гаража обязательны make, model, year, modification, engine, hours, notes; неизвестные текстовые особенности передаются пустой строкой. `catalogVerified: false` означает, что ручное описание ещё не сверено с каталогом. Запись: bikeId, title (3–140), body (10–10000), kind, visibility. Комментарий: body (1–2000).

## Ошибки

```json
{
  "error": {
    "code": "AUTH_REQUIRED",
    "message": "Войдите в аккаунт.",
    "requestId": "req-1"
  }
}
```

400 — неверные поля; 401 — нет сессии / ошибка входа; 403 — Origin, заголовок клиента или CSRF; 404 — отсутствующий либо недоступный объект; 409 — занятый аккаунт / мотоцикл с историей; 413 — тело больше 64 КБ; 429 — лимит; 500 — внутренняя ошибка без деталей. Закрытый объект не раскрывает существование через отдельный статус.

Auth: 10 запросов / минуту / IP; общий лимит: 200. Это локальные счётчики одного процесса; при масштабировании понадобятся общие счётчики и отдельные настройки reverse proxy. Пароли хешируются scrypt с солью, токены сессии сохраняются как SHA-256. Текст отображается React как обычный текст; HTML не исполняется.

После изменения схем выполнить `pnpm api:export` и включить обновлённый документ в PR.

## Локации и модерация

| Метод и путь                                 | Результат                                                                 |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| GET /api/locations                           | Только опубликованные места; city / limit / offset                        |
| POST /api/locations                          | Авторизованное предложение; publicationConsent=true; статус pending       |
| GET /api/me/locations                        | Собственные предложения всех статусов                                     |
| GET /api/locations/{id}                      | Опубликованное место либо собственное / доступное модератору              |
| GET /api/locations/{id}/decisions            | Причины решений только автору / модератору, последние 50                  |
| GET /api/moderation/locations                | Очередь pending, только модератор                                         |
| POST /api/moderation/locations/{id}/decision | publish / reject из pending; hide из published; expectedStatus обязателен |
| POST /api/reports                            | Жалоба на публичный доступный post / location                             |
| GET /api/moderation/reports                  | Открытые жалобы, только модератор                                         |
| POST /api/moderation/reports/{id}/decision   | dismiss / hide, обязательная причина                                      |

Поле role в собственной сессии не редактируется через API; публичный профиль его не возвращает. Решение и аудит записываются в одной транзакции. Повторное решение после изменения статуса — 409. Открытая жалоба одного автора на один объект не дублируется. Жалоба на закрытую / скрытую запись или неопубликованную точку — 404 без раскрытия данных.

Скрытые записи не попадают в ленту и доступны по прямому адресу только автору. Автор получает hidden=true, может изменить текст или удалить запись, но не может вернуть её в публичный доступ. Новые комментарии запрещены. Модератор не получает доступ к личным записям через роль или очередь жалоб.

## GPX и покатушки

| Метод и путь                                   | Результат                                                                   |
| ---------------------------------------------- | --------------------------------------------------------------------------- |
| POST /api/tracks/preview                       | Авторизованная обработка gpx / trimM; чистая геометрия, без сохранения      |
| POST /api/tracks                               | Приватный оригинал + серверная очищенная геометрия, pending                 |
| GET /api/tracks                                | Published; city / limit / offset                                            |
| GET /api/me/tracks                             | Собственные треки всех статусов                                             |
| GET /api/tracks/{id}                           | Published либо автор / модератор; всегда без оригинала                      |
| GET /api/tracks/{id}/original                  | Только автор, JSON gpx                                                      |
| GET /api/tracks/{id}/gpx                       | Очищенный GPX для доступного трека, application/gpx+xml                     |
| GET /api/tracks/{id}/decisions                 | Последние 50 решений, автор / модератор                                     |
| GET /api/moderation/tracks                     | Pending, только модератор                                                   |
| POST /api/moderation/tracks/{id}/decision      | Publish / reject / hide, expectedStatus и причина                           |
| POST /api/rides                                | Опубликованный trackId, дата UTC / offset, timezone, capacity, meetingNotes |
| GET /api/rides                                 | Предстоящие open на published-треках; city / limit / offset                 |
| GET /api/me/rides                              | Организованные / pending / accepted, в том числе отменённые                 |
| GET /api/rides/{id}                            | Публичная карточка без точки сбора; скрытый трек — только организатор       |
| GET /api/rides/{id}/membership                 | Собственный статус или organizer                                            |
| POST /api/rides/{id}/join                      | Pending; повторный запрос идемпотентен                                      |
| POST /api/rides/{id}/leave                     | Left; освобождает место                                                     |
| GET /api/rides/{id}/meeting                    | Организатор либо accepted на предстоящем open / published событии           |
| GET /api/rides/{id}/members                    | Только организатор, максимум 100 записей, активные первыми                  |
| POST /api/rides/{id}/members/{userId}/decision | Accept / decline, только организатор                                        |
| POST /api/rides/{id}/cancel                    | Отмена только организатором, повтор идемпотентен                            |

Изменения защищены сессией / CSRF / Origin как остальные ресурсы. Обработка GPX ограничена 10 запросами в минуту на маршрут API / IP; загрузки — bodyLimit 512 КБ, содержимое GPX ≤400 000 байт. Превью и загрузка используют один серверный обработчик: клиент не может подменить geometry, distance или status. DTD / ENTITY запрещены, XML-парсер не загружает внешние ресурсы. Точки времени, высота, имена и extensions не входят в публичную версию. Ввод meetingNotes не входит в публичный ответ Ride.

Радиусы считаются в метрах на сфере; удаляются точки в зонах краёв и связи, пересекающие их. DistanceM — только оставшиеся участки, не длина исходной поездки. Сегменты не склеиваются. Проверки GPX ограничивают глубину XML, число точек / сегментов, диапазоны координат и скачки. Полная XSD-валидация и GPX 1.0 / rte / wpt не реализованы.

Capacity 2–50 **включает организатора**. Pending не занимает место. Изменения заявок и отмена блокируют одну строку выезда в транзакции; принятие проверяет число accepted под этой блокировкой. RIDE_FULL — 409. Максимум 100 активных заявок. Declined не может подать повторную заявку; left может. Удаление / отзыв accepted организатором и редактирование события пока не реализованы.

Дата: 15 минут–366 дней вперёд; сервер требует явный UTC Z или offset. Разрешённые IANA-зоны описаны в контракте; timezone определяет отображение сохранённого момента. Встреча недоступна участнику после выхода, отмены, скрытия трека или начала события. Полученные ранее данные нельзя отозвать с устройства.

## Доступ и уведомления · 0.6

`Session.user.emailVerified` виден только владельцу сессии.

| Метод | Адрес                          | Поведение                                                               |
| ----- | ------------------------------ | ----------------------------------------------------------------------- |
| POST  | /api/auth/password/request     | `{email}`, одинаковый ответ 202 для существующего и неизвестного адреса |
| POST  | /api/auth/password/reset       | `{token,password}`, одноразовый сброс, отзыв всех сеансов               |
| POST  | /api/auth/email/request        | Сессия + CSRF, повторное письмо подтверждения                           |
| POST  | /api/auth/email/verify         | `{token}`, подтверждение только явным POST                              |
| GET   | /api/me/notifications          | Только свои, limit 1–50 / offset, nextOffset и unreadCount              |
| POST  | /api/me/notifications/:id/read | Сессия + CSRF, только адресат; идемпотентный 204                        |

Токены — 32 случайных байта, в account_tokens только SHA-256. Проверка назначения, срока и однократное потребление выполняются транзакционно с блокировкой пользователя. Письма очереди содержат исходную ссылку до обработки и требуют приватного хранения. В production запись запрещена без подтверждённого email, кроме операций доступа и чтения уведомлений. Ссылки передают токен через фрагмент, не query string. [Эксплуатация почты](../runbooks/pilot.md).

## Данные аккаунта и события · 0.7

`POST /api/me/export` с `{password}` выдаёт JSON-вложение собственных данных после повторной проверки пароля. `POST /api/me/delete` с `{password,confirmation:"УДАЛИТЬ АККАУНТ"}` удаляет данные основной базы и возвращает 204. Обе операции требуют сессию, CSRF и заголовок клиента, доступны и неподтверждённому аккаунту. Ограничения и последствия: [спринт 05](../sprint-05.md).

`Report.targetType` теперь включает `ride`. `Ride.hidden` указывает скрытие модератором. Опубликованные маршруты не делают скрытое событие публичным: карточка доступна только организатору/модератору, приватные сборы — только организатору. Заявки и подтверждения на скрытом событии запрещены; прошлые сведения о сборе не копируются в уведомления.

## Демонстрационный каталог · 0.8

Каталог: `GET /api/catalog` доступен гостям и возвращает `{demo:true,items:CatalogProduct[]}`. Типы товара и строгая схема ответа включают категорию, артикул, демонстрационную цену в рублях, характеристики и вымышленную применимость. Пользовательские данные в запрос не передаются. Подбор в интерфейсе использует собственный `/api/me/bikes` и общую функцию сравнения из `@enduro/contracts`. Пустые поля или несовпадение не подтверждают применимость. Сервер не принимает изменения каталога; заказов и оплаты нет. [Проверка магазина](../sprint-06.md).

## Личный гараж и ТО · 0.9

Сервисные планы и история доступны только владельцу мотоцикла. Версия плана защищает выполнение, архив и восстановление от повторного изменения устаревшей вкладкой. Сервисные данные входят в личную выгрузку и удаление аккаунта. Бортжурнал поддерживает `bikeId` и `kind` в `/api/me/posts`. [Маршруты API и ограничения](../sprint-07.md).
